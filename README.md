# AI Document Assistant

A Python project for learning document retrieval, RAG,
LangChain, LangGraph, APIs, testing, and CI/CD.

## Local setup

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements-dev.txt
```

## Run

```bash
python -m app.main
```

## Test

```bash
python -m pytest -q
```
